# Задание 01 - Параллельные источники данных

## Цель
Сделать Kotlin/JVM консольное приложение, которое параллельно запускает 3 независимые длительные операции.

## Что реализовано
- 3 источника с задержками: users (1800 мс), sales (1200 мс), weather (2500 мс)
- Mock JSON в `src/main/resources`
- Параллельное выполнение через `supervisorScope + async/await`
- Замер общего времени выполнения
- Понятная обработка ошибок по каждому источнику
- Принудительная ошибка через `FORCE_FAIL_SOURCE=users|sales|weather`

## Сборка
```bash
gradle build
```

## Запуск
```bash
gradle run
```

Демонстрация ошибки:
```bash
FORCE_FAIL_SOURCE=weather gradle run
```

## Проверка
- Общее время обычно около ~2500 мс (признак параллельности)
- Результаты всех источников выводятся в консоль
- При падении одного источника программа не падает целиком

## Ограничения и допущения
- Случайная ошибка включена для демонстрации отказоустойчивости (`15%` на источник).
- Формат JSON фиксированный и локальный.
