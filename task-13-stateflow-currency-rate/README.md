# Задание 13 - StateFlow: курс валют

## Цель
Сделать Android-приложение с курсом USD/RUB, который обновляется каждые 5 секунд, плюс кнопка мгновенного обновления.

## Что реализовано
- Состояние на базе `MutableStateFlow`
- Автообновление каждые 5 секунд
- Кнопка `Обновить сейчас`
- Хранение предыдущего значения и направление изменения (стрелка)
- Состояние сохраняется при повороте

## Сборка
```bash
./gradlew assembleDebug
```

## Запуск
Запуск выполняется из Android Studio.

## Проверка
- Курс автоматически меняется каждые 5 секунд
- По кнопке курс обновляется сразу
- Направление роста/падения отображается корректно
- Значение не сбрасывается при повороте экрана

## Ограничения и допущения
- Курс эмулируется случайными значениями.
