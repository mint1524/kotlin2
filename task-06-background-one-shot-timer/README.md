# Задание 06 - Одноразовый фоновый таймер

## Цель
Сделать Android-приложение, где пользователь задает число секунд, запускает таймер, получает уведомление по завершении, после чего сервис останавливается.

## Что реализовано
- Поле ввода количества секунд
- Проверка некорректного ввода (пусто, 0, отрицательное)
- Одноразовый сервис с задержкой
- Уведомление: `Таймер завершён! Время вышло`
- Автоостановка сервиса после завершения

## Сборка
```bash
./gradlew assembleDebug
```

## Запуск
Запуск выполняется из Android Studio.

## Проверка
- Корректное число запускает таймер
- По окончании приходит уведомление
- Сервис завершается сам
- Ошибочные значения обрабатываются без падений

## Ограничения и допущения
- Используется сервисный подход с учетом ограничений версий Android.
