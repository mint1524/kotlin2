# Задание 14 - Компас

## Цель
Сделать Android-компас, который показывает азимут и поворачивает стрелку на магнитный север по данным сенсоров.

## Что реализовано
- `SensorManager` + акселерометр и магнитометр
- Расчет азимута через rotation matrix
- Плавный поворот стрелки (`animateFloatAsState`)
- Подписка на сенсоры на `ON_RESUME`, отписка на `ON_PAUSE`
- Обработка отсутствия необходимых сенсоров
- Минималистичный темный UI

## Сборка
```bash
./gradlew assembleDebug
```

## Запуск
Запуск выполняется из Android Studio, предпочтительно на физическом устройстве.

## Проверка
- Азимут меняется при повороте устройства
- Стрелка поворачивается плавно
- В фоне слушатели сенсоров отключаются
- При отсутствии сенсоров выводится понятная ошибка

## Ограничения и допущения
- Эмулятор может давать неточные показания сенсоров.
