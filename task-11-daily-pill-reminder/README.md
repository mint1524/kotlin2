# Задание 11 - Ежедневное напоминание о таблетке (AlarmManager)

## Цель
Сделать ежедневное уведомление в 20:00 с включением/выключением, показом следующего времени и восстановлением после перезагрузки.

## Что реализовано
- Планирование через `AlarmManager.setExactAndAllowWhileIdle`
- Постановка на ближайшие 20:00
- UI-переключатель состояния и вывод следующего времени
- `BroadcastReceiver` с текстом `Время принять таблетку!`
- `BOOT_COMPLETED` для восстановления расписания
- Сохранение состояния в `SharedPreferences`

## Сборка
```bash
./gradlew assembleDebug
```

## Запуск
Запуск выполняется из Android Studio.

## Проверка
- Включение ставит ближайшее расписание
- Уведомление приходит в назначенное время
- Выключение отменяет будущие срабатывания
- После перезагрузки включенное напоминание восстанавливается

## Ограничения и допущения
- Разрешения/политики точных будильников зависят от версии Android и прошивки.
