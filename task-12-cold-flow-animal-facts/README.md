# Задание 12 - Cold Flow: факты о животных

## Цель
Сделать Android-приложение, где по кнопке генерируется случайный факт через `cold Flow<String>`.

## Что реализовано
- `ViewModel.getRandomFact(): Flow<String>` как cold flow
- Случайная задержка 1500..3000 мс внутри flow
- Compose UI: кнопка, loader, карточка факта
- Генерация происходит только по нажатию
- Текущий факт хранится в ViewModel и переживает поворот

## Сборка
```bash
./gradlew assembleDebug
```

## Запуск
Запуск выполняется из Android Studio.

## Проверка
- Новый факт появляется только после нажатия
- Каждое новое получение проходит через delay
- При повороте экрана факт не генерируется заново автоматически
- Видны loading-state и итоговая карточка

## Ограничения и допущения
- Набор фактов локальный и статический.
