# Модуль 4

Репозиторий содержит 14 независимых заданий модуля 4.

## Структура

- `task-01-parallel-data-sources` (Kotlin/JVM, консоль)
- `task-02-json-duplicates-timeout` (Kotlin/JVM, консоль)
- `task-03-github-search-debounce` (Android)
- `task-04-social-feed-concurrency` (Android)
- `task-05-foreground-timer-service` (Android)
- `task-06-background-one-shot-timer` (Android)
- `task-07-bind-random-number-service` (Android)
- `task-08-workmanager-photo-pipeline` (Android)
- `task-09-parallel-weather-report` (Android)
- `task-10-location-and-reverse-geocoding` (Android)
- `task-11-daily-pill-reminder` (Android)
- `task-12-cold-flow-animal-facts` (Android)
- `task-13-stateflow-currency-rate` (Android)
- `task-14-compass` (Android)

## Требования к среде

- JDK 17+
- Gradle 8+
- Android Studio Iguana+
- Android SDK 34+

## Порядок запуска

1. Сначала выполняется проверка консольных заданий (`task-01`, `task-02`).
2. Android-задания собираются по одному в Android Studio командой `assembleDebug`.

## Примечания

- У каждого задания есть собственный `README.md` с целью, реализацией, инструкциями запуска и проверками.
- Mock-данные и ресурсы лежат внутри соответствующих папок заданий.
