# Задание 08 - WorkManager: цепочка обработки фото

## Цель
Сделать последовательную цепочку из 3 worker'ов: сжатие -> водяной знак -> загрузка, с отображением прогресса и результата.

## Что реализовано
- `CompressWorker`, `WatermarkWorker`, `UploadWorker`
- Последовательная цепочка через `beginUniqueWork().then().then()`
- Передача данных между шагами (`file_path`)
- Обновление текущего шага и прогресса в UI
- Отображение финального результата или ошибки

## Сборка
```bash
./gradlew assembleDebug
```

## Запуск
Запуск выполняется из Android Studio.

## Проверка
- Шаги выполняются строго последовательно
- UI показывает текущий этап
- При ошибке цепочка завершается с ошибкой
- В случае успеха выводится итог загрузки

## Ограничения и допущения
- Обработка фото и загрузка имитируются локальными файлами.
