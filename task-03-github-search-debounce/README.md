# Задание 03 - Поиск GitHub-репозиториев с debounce

## Цель
Сделать Android-экран поиска по локальному JSON с debounce и отменой предыдущего поиска.

## Что реализовано
- Поле ввода `TextField`
- Локальный датасет: `app/src/main/assets/github_repos.json` (60 записей)
- Debounce через `Job.cancel() + delay(500)`
- Поиск по имени, описанию и языку
- Состояния UI: пусто, загрузка, результаты, ничего не найдено

## Сборка
```bash
./gradlew assembleDebug
```

## Запуск
Запуск выполняется из Android Studio на эмуляторе или устройстве.

## Проверка
- При быстром вводе поиск не запускается мгновенно на каждый символ
- Новый ввод отменяет предыдущую задачу поиска
- Во время ожидания показывается лоадер
- Результаты фильтруются корректно

## Ограничения и допущения
- Используется локальный JSON, не сетевой API.
