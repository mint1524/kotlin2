# Задание 10 - Локация и обратное геокодирование

## Цель
Сделать Android-приложение с кнопкой `Получить мой адрес`: запрос прав, получение координат, reverse geocoding и вывод адреса.

## Что реализовано
- Runtime permissions: `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`
- Получение координат через `FusedLocationProviderClient`
- Обратное геокодирование через `Geocoder`
- Состояния UI: загрузка, успех, ошибка
- Раздельный вывод адреса и координат

## Сборка
```bash
./gradlew assembleDebug
```

## Запуск
Запуск выполняется из Android Studio на устройстве (предпочтительно) или эмуляторе с заданной геопозицией.

## Проверка
- При первом запуске корректно запрашиваются разрешения
- Во время получения локации показывается индикатор
- Адрес и координаты отображаются отдельно
- Отказ в доступе/ошибки обрабатываются сообщением

## Ограничения и допущения
- Наличие и качество `Geocoder` зависит от устройства/сервисов.
