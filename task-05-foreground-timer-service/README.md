# Задание 05 - Foreground Service с таймером

## Цель
Сделать Android-приложение с foreground service, который считает секунды и обновляет уведомление и UI.

## Что реализовано
- Foreground service + notification channel
- Кнопка `Старт` запускает сервис
- Кнопка `Стоп` останавливает сервис и убирает уведомление
- Уведомление обновляется каждую секунду: `Прошло X секунд`
- То же значение отображается на экране через `StateFlow`

## Сборка
```bash
./gradlew assembleDebug
```

## Запуск
Запуск выполняется из Android Studio.

## Проверка
- После старта появляется постоянное уведомление
- Счетчик растет каждую секунду в UI и уведомлении
- После остановки уведомление исчезает

## Ограничения и допущения
- На Android 13+ требуется разрешение на уведомления.
