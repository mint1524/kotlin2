# Задание 04 - Социальная лента с конкурентной загрузкой

## Цель
Сделать Android-ленту, где карточки постов догружают аватар и комментарии параллельно и отображаются по мере готовности.

## Что реализовано
- Лента из `posts.json` (8 постов)
- Параллельная догрузка аватара и комментариев для каждого поста
- Независимые состояния карточек: `Loading / Ready / Error`
- Кнопка `Обновить` отменяет текущую загрузку и запускает заново
- Чтение JSON вынесено с main thread (`Dispatchers.IO`)

## Сборка
```bash
./gradlew assembleDebug
```

## Запуск
Запуск выполняется из Android Studio.

## Проверка
- Карточки меняют состояние независимо друг от друга
- Ошибка одной карточки не ломает весь экран
- `Обновить` перезапускает загрузку и отменяет старые job

## Ограничения и допущения
- Аватарка имитируется первой буквой автора.
- Ошибки частично эмулируются случайно.
