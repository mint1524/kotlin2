# Задание 02 - Поиск дубликатов JSON с таймаутом и отменой

## Цель
Сделать Kotlin/JVM консольное приложение, которое рекурсивно ищет JSON-файлы, считает SHA-256 параллельно, находит дубликаты и поддерживает общий таймаут.

## Что реализовано
- Рекурсивный поиск `.json` через `Files.walk(...)`
- Параллельный расчет SHA-256 с корутинами
- Группировка дубликатов по хэшу
- Общий таймаут через `withTimeoutOrNull`
- Сообщение при отмене: `Поиск прерван по таймауту`
- Добавлена тестовая `sample-data/` с дубликатами

## Сборка
```bash
gradle build
```

## Запуск
```bash
gradle run --args="./sample-data 5"
```

Аргументы:
- arg1: путь к папке
- arg2: таймаут в секундах

Демонстрация таймаута:
```bash
gradle run --args="./sample-data 1"
```

## Проверка
- При нормальном таймауте выводятся группы дубликатов
- При маленьком таймауте операция корректно прерывается
- Отмена распространяется на всю операцию

## Ограничения и допущения
- Фильтрация входа по расширению `.json`.
- Хэш считается потоково из файла.
