# Задание 07 - Bind Service: случайное число

## Цель
Сделать Android-приложение, которое подключается к bind service и показывает случайное число 0..100 каждую секунду.

## Что реализовано
- `RandomNumberService` с `Binder`
- Выдача значений через `StateFlow`
- Обновление числа раз в секунду
- Кнопки `Подключиться` и `Отключиться`
- Управление подключением/отключением в Activity

## Сборка
```bash
./gradlew assembleDebug
```

## Запуск
Запуск выполняется из Android Studio.

## Проверка
- После подключения число меняется каждую секунду
- После отключения обновление прекращается
- Повторные подключения работают стабильно

## Ограничения и допущения
- Генерация запускается в жизненном цикле сервиса.
