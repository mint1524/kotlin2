# Задание 09 - Параллельный отчет по погоде

## Цель
Сделать Android-приложение, которое параллельно собирает погоду по нескольким городам и показывает прогресс через foreground-уведомление и UI.

## Что реализовано
- `CoroutineWorker` с `setForeground(...)`
- Параллельная загрузка погоды для 4 городов
- Прогресс выполнения (`done/total/status`)
- Финальный отчет со средней температурой
- Экран запуска и наблюдения статуса

## Сборка
```bash
./gradlew assembleDebug
```

## Запуск
Запуск выполняется из Android Studio.

## Проверка
- Уведомление появляется сразу после старта
- Прогресс обновляется по мере завершения городов
- Итог содержит среднюю температуру и детальный отчет
- Работа не теряется при уходе в фон

## Ограничения и допущения
- Погода эмулируется случайными значениями.
